落地说明

本次只产出设计稿，未修改工程内任何代码与资源。下面是界面与现有功能的对应关系，以及主题改造的接入点。

功能对应

  • 首页 ← HomeView（新建 / 最近打开）
  • 基础信息 ← BaseInfoView（4 组 20 项）
  • 组件信息 ← AssemblyView（组件组 + 文件 / 忽略列表）
  • 应用程序图标 ← AppIconInfoView
  • 注册表 ← RegistryView、PasswordDialog
  • 多语言 ← LanguageView / LanguageFileView
  • 结束界面 ← EndView
  • 弹窗 ← SettingControl、PlugInManager、TargetPath、编译等待

主题接入

沿用现有 Themes/DefaultColor.xaml 与 Black.xaml 两套字典：把上表的令牌补进字典，代码里统一用 DynamicResource 引用即可在运行时切换。

主要改动是把散落的写死颜色（LightGray、#FF9FC7F7、Black）收编为令牌；新增约 8 个键：bg、text2、text3、ok、warn、danger 及两个弱色底。

结构与取舍

  • 画布 + 卡片双层：窗体底色是画布，内容一律装进 12px 圆角卡片，空的地方读作画布而不是「没做完」。
  • 首页不显示工程结构栏（没有打开的工程），打开或新建后左栏才出现，避免首页出现「点了没反应」的工程页入口。
  • 控件 32、表格行 36、页头 52，密度介于「网页」和「老式工具」之间，1296 宽仍能一屏看完全部字段。
  • 页头只留标题和动作按钮，删掉每页那句解释文案——工具不需要推销自己。
  • 左栏只放工程结构，工具类入口统一在顶部菜单；体积与编译状态在状态栏。
